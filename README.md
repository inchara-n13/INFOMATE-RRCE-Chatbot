# INFOMATE – RRCE College Information Chatbot

INFOMATE is a bilingual rule-based chatbot developed to provide quick information about Rajarajeswari College of Engineering (RRCE).

## Features

- English and Kannada language support
- Course information
- Fee information
- Hostel information
- Library information
- Sports facilities
- Academic information
- Laboratory information
- Transport information
- Placement information
- Anti-ragging and safety information
- Suggested questions
- Enter-to-send support
- Automatic Kannada input detection

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

INFOMATE uses rule-based keyword matching to identify the user's query and provide a predefined response.

The chatbot supports both English and Kannada input. Kannada text is automatically detected and the response is provided in Kannada.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start chatting with INFOMATE.
